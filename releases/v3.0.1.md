# PenguinPDF 3.0.1

A desktop update for macOS and Windows.

- Edit Text better preserves source font weight when you insert characters
  missing from an embedded font subset, including IBM Plex Sans Light.
- Edited lines retain their original reading order on supported PDFs, so
  copying or extracting text doesn't move those lines to the end of the page.
- Expanded offline font coverage and improved paragraph handling in worksheets.
- Restored the rounded macOS icon and improved the Windows taskbar icon.
