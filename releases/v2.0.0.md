# PenguinPDF 2.0.0

PenguinPDF is a free, local-first PDF toolbox for macOS and Windows. Your
documents are processed on your computer, without uploads or an account.

## What's new

- Edit Text: update existing text in selectable and scanned PDFs, with text
  formatting, undo/redo, and local text recognition.
- Annotate PDF: add text, highlights, drawing, shapes, images, and secure
  redactions. Cosmetic covers remain distinct from redactions.
- Fill & Sign: complete supported PDF form fields, place checkmarks, and add
  a drawn or imported signature.
- Improved PDF-to-Word conversion, including editable paragraphs and lists,
  colors, portable font choices, graphics preservation, and conversion notices.
- A more consistent workflow across page tools, conversion, compression,
  metadata removal, and password protection, with previews and saved-file reuse.
- Refreshed app icons, including a Windows-specific transparent icon.

## Choose your installer

| Computer | Asset |
| --- | --- |
| Mac with Apple Silicon (M1 or newer) | `PenguinPDF-2.0.0-macOS-Apple-Silicon.dmg` |
| Mac with an Intel processor | `PenguinPDF-2.0.0-macOS-Intel.dmg` |
| Windows x64, standard installer | `PenguinPDF_x64-setup.exe` |
| Windows x64, MSI alternative | `PenguinPDF_x64_en-US.msi` |

Both Mac builds are Developer ID signed, notarized, and stapled. The Windows
installers are unsigned and may display a Microsoft Defender SmartScreen
warning. They are not represented as Authenticode-signed or trusted installers.
Download only from this repository or the official PenguinPDF website and
compare the SHA-256 checksum when verifying a download.

`SHA256SUMS.txt` contains checksums for every installer. `PenguinPDF_x64.dmg`
is a byte-identical alias of the Intel build for older download links; Apple
Silicon users should choose the explicitly named Apple Silicon installer.

## Conversion and editing notes

- PDF to Word works locally using the built-in conversion engine and bundled
  Tesseract OCR. Ordinary text and supported lists/tables remain editable.
  Complex content may be preserved as images; font substitutions and visual
  preservation are disclosed. Layout can vary between word processors.
- Word to PDF requires a separately installed
  [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/).
  PenguinPDF does not bundle or automatically install LibreOffice.
- Secure redaction rebuilds affected pages and can remove their selectable text
  and interactive fields. Review the confirmation before exporting.
- Drawn/imported signatures are visual signatures, not certificate-based
  digital signatures. Field locking sets read-only flags, not encryption.
