# PenguinPDF 3.0.0

A desktop refresh for macOS and Windows. Documents are still processed locally,
and all tools remain free. PenguinPDF for iPhone is coming soon.

- New app artwork and a larger, clearer area for browsing or dropping files.
- Settings puts the app version, updates and licenses in one place.
- Edit Text improves cursor placement and committing active edits when saving a copy.
- Compression protects existing output on failure. Word-to-PDF accepts only the
  expected output from its own conversion job.
